- App name: Atlas FieldOps

- Support URL: `https://atlasfieldops.com/help`
- Privacy Policy URL: `https://atlasfieldops.com/privacy`

- Contact email: `support@atlasfieldops.com`

## Android Permissions

Expected permissions:

- Fine location
- Coarse location
- Camera
- Audio recording
- Media image access

Only request a permission when the field workflow needs it.

## Store Listing Preparation

Prepare before public release:

- Short description focused on offline field data collection.
- Full description covering assignments, forms, beneficiaries, GPS, attachments, drafts, sync, and corrections.
- Screenshots for login, assignments, entity selection, form entry, drafts, sync center, and diagnostics.
- Privacy disclosure confirming that form answers are customer-controlled operational data.
- Support contact and issue escalation process.

## Build Outputs

For pilot testing:

- APK for direct controlled installation.

For Play Store:

- Android App Bundle (AAB).

Native signing keys, Play Console access, and automated build credentials must be configured before generating production artifacts.
